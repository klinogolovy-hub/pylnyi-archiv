# Пыльный Архив — Android

Игра целиком живёт в `app/src/main/assets/index.html`, а приложение — это обёртка на WebView.

## Как получить APK

**Способ 1. Без установки программ (GitHub Actions).**
1. Создайте пустой репозиторий на github.com и загрузите в него всё содержимое этой папки.
2. Откройте вкладку Actions, запустите «Build APK» (Run workflow).
3. Через пару минут скачайте артефакт `PylnyArchiv-apk`. Внутри `app-debug.apk`.

**Способ 2. Android Studio.** Откройте эту папку, затем Build → Build APK(s).

**Способ 3. Командная строка** (нужны JDK 17 и Android SDK): `./gradlew assembleDebug`. Файл будет в `app/build/outputs/apk/debug/`.

## Установка на телефон
Передайте `app-debug.apk` на телефон и откройте его. Если Android спросит, разрешите установку из этого источника.

## Заметки
- Шрифт подгружается из интернета. Без сети игра работает, но с обычным моноширинным шрифтом.
- Прогресс сохраняется на телефоне между запусками.
